# SITEFORMO — CURRENT PRODUCTION LOGIC

## Final flow

Questionnaire → Design Direction → Homepage Interaction Style → Production Confirmation → Automatic Production Email → Protected Review System → Revision Phase → Final ZIP Delivery

## Homepage interaction style

Available only for Business, Reference and Advanced. Starter skips this stage.

Final options:

- Smooth: calm homepage feeling and soft visual behavior.
- Dynamic: active homepage presentation and stronger movement.
- Premium: cinematic depth and layered visual behavior.

This is not a template, animation pack, or color palette. It changes how the selected design behaves visually and emotionally.

## Protected review system

Preview access is not final delivery. Clients receive a protected preview environment, structured revision form, and final ZIP only after revision completion and final approval.

The client must not receive before final approval:

- ZIP files
- source files
- admin access
- editable builder access

## Revision rules

Starter includes 1 revision round. Business, Reference and Advanced include 2 revision rounds.

One revision round means one grouped list of changes submitted together.

Included: text edits, image replacement, spacing refinements, section improvements, small visual polishing.

Not included: new concept, changing design direction, homepage rebuild, multiple alternative versions, complete restructuring.

## Example system direction

Examples are the visual DNA of production. The backend must collect and preserve selected example, viewed examples, entry source, time spent, design direction, interaction style, package and business type.
